Cutscene videos for Bus' a Lead.

Drop these .mp4 files here and they will play automatically at the mapped
game events. If a file is missing, the game skips it gracefully (never freezes).

  title.mp4       - Looping, muted background on the Config / Splash screen.
  renege.mp4      - When a renege is caught (RENEGE CONFIRMED / FALSE ACCUSATION).
  hardset.mp4     - When a player is Hard Set / Busted.
  concession.mp4  - When a hand is conceded (pre-play give-up).
  trashtalk.mp4   - Random AI trash-talk after DooLow/PapaCap takes a book.

Notes:
- Event cutscenes are full-screen and blocking, with a "Skip" button and
  tap-anywhere-to-skip. They auto-dismiss after 5s max, and immediately if the
  file errors or stalls.
- Keep files short (a few seconds). H.264 .mp4 recommended for browser support.
